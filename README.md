# React + Vite

本项目为基于 Vite 的 React 应用，支持 HMR 和 ESLint。

---

## 安装与启动

1. **安装依赖**
   ```sh
   npm install
   # 或者
   yarn install
   ```
2. **启动开发环境**
   ```sh
   npm run dev
   # 或者
   yarn dev
   ```
3. **访问应用**
   - 默认在 http://localhost:5173 打开。

4. **激活码/授权（如有）**
   - 如需激活码，请联系管理员获取，并在应用首次启动时输入。
   - 若无激活码需求，可忽略此步。

## 用户玩法说明

### 1. 如何开始游戏
- 打开应用后，首页会显示一个故事标题和相关主题。
- 点击“开始”按钮即可进入当前故事的闯关页面。

### 2. 如何切换/选择故事
- 在首页或故事列表页，可以浏览所有可用故事。
- 点击某个故事的标题，即可切换到该故事进行挑战。
- 有些版本支持“下一题”或“随机故事”按钮，便于快速切换。

### 3. 如何操作词语
- 每一轮会显示若干词语（words），顺序是打乱的。
- 玩家需要**拖拽**或**点击**词语，将它们按正确顺序放入下方的句子框中，组成完整的句子。
- 如果放错了，可以点击“撤回”按钮，或直接将词语拖出句子框，恢复到原位。
- 句子框支持多次调整，直到顺序正确。

### 4. 得分与闯关规则
- 每拼对一句完整的句子，即可得分。
- 一般每个故事有2-3轮，每轮完成后自动进入下一轮。
- 全部句子拼对后，显示本故事的完整故事内容和总得分。
- 有些版本支持排行榜或闯关进度。

### 5. 常见问题与帮助
- **词语顺序拼错怎么办？** 直接拖动调整顺序，或使用撤回按钮。
- **如何重玩当前故事？** 点击“重玩”或“刷新”按钮即可。
- **如何查看完整故事？** 通关后会自动显示完整故事内容。
- **遇到卡顿或异常？** 可尝试刷新页面或联系开发者。

如有更多玩法建议或遇到问题，欢迎反馈给开发团队！

## 故事数据维护规则与步骤

### 1. words 字段拆分规则
- 每一句话的 `words` 字段，需将句子拆分为词或短语（主语、谓语、宾语、修饰语等），每个词/短语单独作为一个元素。
- 连接词（如“虽然”“因为”“如果”等）单独作为一个元素。
- 标点符号（逗号、句号等）单独作为一个元素，且每句话只出现一次逗号和一次句号，位置与语法一致。
- 例如：
  - 错误：`["虽然外面下着雨", "，", "小狗还是决定出门散步", "。"]`
  - 正确：`["虽然", "外面", "下着雨", "，", "小狗", "还是", "决定", "出门", "散步", "。"]`

### 2. 标点符号规范
- 每句话只能有一个逗号（连接词后）和一个句号（句末）。
- 不允许出现多个逗号或句号。
- 标点符号应单独作为数组元素。

### 3. 句式结构
- 鼓励使用“虽然…，但是…”，“因为…，所以…”，“如果…，就…”等复合句式，体现逻辑关系。
- 句子应尽量简洁明了，结构清晰。

### 4. 维护步骤
1. 新增或修改故事时，严格按照上述拆分和标点规范填写 `words` 字段。
2. 检查 `correctSentence` 字段与 `words` 拆分内容一致。
3. 检查每句话标点符号数量和位置，确保无多余标点。
4. 如需批量修改，可用脚本或AI辅助，但需人工复查格式。
5. 保持故事内容不重复，主题多样。

如有疑问或需批量处理建议，请联系维护者或使用AI助手协助。
